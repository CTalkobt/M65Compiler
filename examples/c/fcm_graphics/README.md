# fcm_graphics

Full-colour characters (64 bytes, a byte a pixel, each pixel a palette entry).

```
make              Build fcm_graphics.prg
make check        Build fcmcheck.prg (runs 100 frames, then reports)
make clean        Remove build artifacts
make run          Build and run in xemu (if available)
```

More, and its screen: [doc/examples](../../../doc/examples/README.md#fcm_graphics).
