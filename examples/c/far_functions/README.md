# far_functions

`__far` functions: their code kept in bank 5 and run through a window, with no pragma or option.

```
make          Build fardemo.prg, fardemo.ov1 and fardemo.d81
make clean    Remove build artifacts
make run      Run in xemu with the disk in drive 8
```

More, and its screen: [doc/examples](../../../doc/examples/README.md#far_functions).
