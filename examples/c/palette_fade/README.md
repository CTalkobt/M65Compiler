# palette_fade

Demonstrates mixed C and assembly code with calling conventions and MEGA65 hardware register access.

```
make              Build palette_fade.prg
make clean        Remove build artifacts
make disasm       Generate annotated disassembly listings
make run          Build and run in xemu (if available)
```

More, and its screen: [doc/examples](../../../doc/examples/README.md#palette_fade).
