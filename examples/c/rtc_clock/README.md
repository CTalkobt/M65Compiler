# rtc_clock

The real-time clock in big digits (a 5x7 font of reverse spaces) with the weekday, date, a seconds bar and a stopwatch counted in video frames.

```
make              Build rtc_clock.prg
make check        Build the RTC test, run it in xemu and check the result
make clean        Remove build artifacts
make run          Build and run in xemu (if available)
```

More, and its screen: [doc/examples](../../../doc/examples/README.md#rtc_clock).
