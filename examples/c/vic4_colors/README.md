# vic4_colors

Steps the border and background colours through a struct overlay on `$D020`/`$D021`, ending on white with black text.

```
make              Build vic4_colors.prg
make clean        Remove build artifacts
make run          Build and run in xemu (if available)
```

More, and its screen: [doc/examples](../../../doc/examples/README.md#vic4_colors).
