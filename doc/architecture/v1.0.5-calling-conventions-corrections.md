# v1.0.5 Calling Convention Corrections — superseded

This page used to list documentation corrections made for v1.0.5. Most of
those corrections are now themselves out of date:

- **Frame-pointer setup is no longer unconditional.** It happens only when a
  function has a frame, and the caller's `$FD/$FE` is saved and restored.
- **There is no static `__return_struct_temp`.** The caller passes a pointer
  to its own buffer.
- **The ZP parameters are not at `$20-$27`, and there is no 4-parameter
  limit.** They use the 32-byte block `$10-$2F`.
- **The stack is no longer fixed to page `$01`.**
- **ZP callers can call stack callees across modules.** ln45 generates a
  thunk for the call.

The one point that still holds: the frame pointer is never recalculated
after a call.

The current, verified description is in
[calling-conventions.md](calling-conventions.md).
