# ar45 — Archiver for .o45 Object Files

`ar45` creates and manages `.lib` static library archives containing `.o45` relocatable object files. Libraries enable selective linking — `ln45` only pulls in the members needed to resolve undefined symbols.

## Usage

```bash
ar45 <command> <archive.lib> [files...]
```

## Commands

| Command | Description |
|---------|-------------|
| `c` | Create a new archive from `.o45` files |
| `t` | List archive members (name and size) |
| `x` | Extract all members to the current directory |
| `s` | Print the global symbol index |
| `a` | Add `.o45` files to an existing archive (replaces existing members with the same name) |
| `d` | Delete named members from an archive |
| `-V` / `--version` | Display version and exit |
| `-?` | Display help |

## Archive Format (`.lib`)

```
magic         4 bytes     "a45\0"
version       1 byte      $01
member_count  4 bytes LE
symbol_count  4 bytes LE
[symbol index]
  name        NUL-terminated
  member_idx  4 bytes LE
[members]
  name_len    2 bytes LE
  name        name_len bytes
  data_len    4 bytes LE
  data        data_len bytes (.o45 content)
```

The global symbol index is built automatically by scanning each member's `.o45` export table. This index is used by `ln45` for selective linking.

## Examples

### Create a library

```bash
# Compile library modules
cc45 -c string.c -o string.o45
cc45 -c math.c -o math.o45
cc45 -c io.c -o io.o45

# Bundle into a library
ar45 c stdlib.lib string.o45 math.o45 io.o45
```

### Inspect a library

```bash
# List members
$ ar45 t stdlib.lib
string.o45 (245 bytes)
math.o45 (180 bytes)
io.o45 (320 bytes)

# Show symbol index
$ ar45 s stdlib.lib
_strlen [string.o45]
_strcpy [string.o45]
_add [math.o45]
_mul2 [math.o45]
_putchar [io.o45]
_puts [io.o45]
```

### Link with a library

```bash
# Only modules needed by main.o45 are pulled in
ln45 -prg main.o45 stdlib.lib -o program.prg

# Equivalently:
ln45 -prg main.o45 -l stdlib.lib -o program.prg
```

If `main.o45` imports `_add` and `_puts`, only `math.o45` and `io.o45` are pulled from the library. `string.o45` is not included.

Chain dependencies are resolved iteratively — if `io.o45` imports `_strlen`, then `string.o45` is also pulled in automatically.

### Update a library

```bash
# Recompile one module and update the archive
cc45 -c math.c -o math.o45
ar45 a stdlib.lib math.o45
```

### Remove a module

```bash
ar45 d stdlib.lib io.o45
```

### Extract all members

```bash
ar45 x stdlib.lib
# Extracts string.o45, math.o45, io.o45 to current directory
```

## Common Use Cases

### Building a Standard Library

**Scenario:** Organize standard library functions into a reusable archive.

```bash
# Compile each module separately
cc45 -c lib/string.c -o obj/string.o45
cc45 -c lib/math.c -o obj/math.o45
cc45 -c lib/io.c -o obj/io.o45
cc45 -c lib/memory.c -o obj/memory.o45

# Create library
ar45 c mylib.lib obj/*.o45

# Verify contents
ar45 s mylib.lib
```

### Multi-Project Library

**Scenario:** Share common code across multiple games/projects.

```bash
# Create graphics library (once)
mkdir -p libs/graphics
cc45 -c src/sprite.c -o libs/graphics/sprite.o45
cc45 -c src/palette.c -o libs/graphics/palette.o45
cc45 -c src/vic4.c -o libs/graphics/vic4.o45
ar45 c libs/graphics.lib libs/graphics/*.o45

# Create physics library (once)
mkdir -p libs/physics
cc45 -c src/collision.c -o libs/physics/collision.o45
cc45 -c src/velocity.c -o libs/physics/velocity.o45
ar45 c libs/physics.lib libs/physics/*.o45

# Use both libraries in game
cc45 -c game.c -o game.o45
ln45 -basic -o game.prg game.o45 \
  -l libs/graphics.lib \
  -l libs/physics.lib \
  -l c45.lib
```

### Selective Linking (Reduce Binary Size)

**Scenario:** Only needed functions are linked into the executable.

```bash
# Game only needs certain functions
# main.o45 imports: _sprite_draw, _play_sound, _malloc

ar45 s mylib.lib
# Output: 12 symbols available

ln45 -basic -o game.prg main.o45 -l mylib.lib
# Result: Only modules containing _sprite_draw, _play_sound, and _malloc
#         are pulled in. Other modules stay out. Binary is smaller.
```

### Update Library After Bug Fix

**Scenario:** Recompile one module and update the library without rebuilding everything.

```bash
# Fix bug in physics.c
cd src
vim physics.c
cc45 -c physics.c -o ../obj/physics.o45

# Update archive
cd ..
ar45 a libs/physics.lib obj/physics.o45

# Rebuild game (only links updated module)
ln45 -basic -o game.prg game.o45 -l libs/physics.lib -l c45.lib
```

### Debug vs Release Libraries

**Scenario:** Create separate libraries for debugging and release.

```bash
# Debug version: minimal optimization
cc45 -O0 -c src/physics.c -o debug/physics.o45
cc45 -O0 -c src/graphics.c -o debug/graphics.o45
ar45 c libs/debug.lib debug/*.o45

# Release version: maximum optimization
cc45 -O3 -c src/physics.c -o release/physics.o45
cc45 -O3 -c src/graphics.c -o release/graphics.o45
ar45 c libs/release.lib release/*.o45

# Build with appropriate library
ln45 -basic -o game_debug.prg game.o45 -l libs/debug.lib
ln45 -basic -o game_release.prg game.o45 -l libs/release.lib
```

### Inspecting and Extracting

**Scenario:** Inspect what's in a library and recover object files.

```bash
# List library contents
ar45 t mylib.lib
# string.o45 (2445 bytes)
# math.o45 (1823 bytes)
# io.o45 (3102 bytes)

# Show symbol index (which module exports what)
ar45 s mylib.lib
# _strlen [string.o45]
# _strcpy [string.o45]
# _add [math.o45]
# _puts [io.o45]

# Extract all members for modification
ar45 x mylib.lib
# Now can inspect, modify, and rebuild
```
