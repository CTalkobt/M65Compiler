# nm45 — Symbol Lister for .o45 Object Files

`nm45` lists the symbols (imports and exports) of `.o45` relocatable object files, in the style of Unix `nm`, and can also show the header, relocations, segment sizes, a hex dump and function attributes.

It reads the files produced by `ca45 -c` and `cc45 -c`. `.lib` archives are not read (nm45 points you to `ar45 t`); extract members with `ar45 x` first.

## Usage

```bash
nm45 [options] <file.o45> [...]
```

## Output Format

```
OFFSET TYPE NAME
```

- **OFFSET**: 8-digit hex value — segment-relative offset for exports (the value itself for absolute ones), blank for imports.
- **TYPE**: one letter (below).
- **NAME**: the symbol name as stored in the object.

| Letter | Meaning |
|--------|---------|
| `U` | Undefined — imported symbol (`.extern`) |
| `T` | Text segment export |
| `D` | Data segment export |
| `B` | BSS segment export |
| `Z` | Zero-page segment export |
| `A` | Absolute export (a constant) |
| `W` | Weak export (any segment) — can be overridden by a strong definition |

By default the list is sorted by name, imports and exports together.

## Options

### Symbol display
| Flag | Description |
|------|-------------|
| `-u` | Only undefined (imported) symbols |
| `-g` | Only exported symbols |
| `-n` | Sort by offset (exports first, then imports) |
| `-R` | Reverse the sort order |
| `-p` | No sorting — imports, then exports, in file order |
| `-A`, `-o` | Prepend the file name to each line (`file.o45:offset T name`) |
| `-f` | Append function attributes to functions that have them |

### Object inspection
| Flag | Description |
|------|-------------|
| `-h` | File header: format, CPU, mode flags, segment bases/lengths, options |
| `-x` | Hex dump of the text and data bodies |
| `-r` | Decoded relocation entries |
| `-s` | Segment sizes, one line per file (like `size`) |
| `-a` | All: header, hex dump, relocations, sizes, symbols with function attributes |
| `-V` / `--version` | Display version and exit |
| `-?` / `--help` | Display help |

`-h`, `-x`, `-r` and `-s` replace the symbol listing (unless `-a` is given). With several files and without `-A`, each file's output is preceded by a blank line and `file:`. Unrecognized options are taken as file names.

## Examples

### List symbols

```
$ nm45 amain.o45 autil.o45

amain.o45:
         U print
00000000 T start

autil.o45:
00000000 T print
```

A cc45 object also exports compiler-generated symbols: `_f__sac` (body entry of a SAC function), `_f__param_x` (its static parameter slots), and weak absolute constants (`cc45.mode_zp`/`cc45.mode_stack`, `cc45.zeroPageStart`, `__zp_scratch`..., `__sp_base`, `__static_chain`):

```
$ nm45 math.o45
         U __bp_prog
         U __bp_rom
00000101 W __sp_base
00000006 W __static_chain
00000008 W __zp_scratch
0000000a W __zp_scratch2
0000000c W __zp_scratch3
0000000e W __zp_scratch4
00000000 T _add
00000000 B _add__param_a
00000002 B _add__param_b
00000014 T _add__sac
00000036 T _mul2
00000008 B _mul2__param_a
00000040 T _mul2__sac
00000001 W cc45.mode_zp
00000008 W cc45.zeroPageStart
```

### Search across objects

```
$ nm45 -A amain.o45 autil.o45 | grep print
amain.o45:         U print
autil.o45:00000000 T print
```

### Function attributes

```
$ nm45 -f math.o45 | grep ' T _add$\| T _add '
00000000 T _add  [zp_call leaf uses:- clobbers:- releases:- regs:AX flags:CNZV]
```

The bracket shows the convention (`zp_call`/`stack_call`), the `leaf`, `reentrant` and `zeroalloc` flags, the ZP masks as slot ranges, and the clobbered registers and flags. ZP slots are printed relative to `$03` (bit 0 = `$03`); for cc45 objects, whose masks are relative to `cc45.zeroPageStart`+1 (`$09`), the printed addresses are therefore 6 too low. The SAC and ISR flags are not shown.

### Header

```
$ nm45 -h amain.o45
File:    amain.o45
Format:  .o45 (32-bit)
CPU:     45GS02 ($45)
Mode:    $8800 (SIZE32 CPUEXT)
Text:    base=$0000  len=7
Data:    base=$0000  len=3
BSS:     base=$0000  len=0
ZP:      base=$0000  len=0
Options:
  type=$02 OS [05]
  type=$03 ASM "ca45"
```

Options other than FNAME/OS/ASM/AUTHOR/CREATED are labelled `USER` (e.g. `$10` sub-segment, `$11` line info, `$12` debug symbols) and shown as text or hex bytes.

### Relocations

```
$ nm45 -r amain.o45
Text relocations (3):
  0001  R_LOW       DATA
  0003  R_HIGH      DATA    extra=$00
  0005  R_WORD      EXTERN  print
```

### Segment sizes

```
$ nm45 -s amain.o45 autil.o45 math.o45
    text     data      bss       zp    total  filename
       7        3        0        0       10  amain.o45
      17        0        0        0       17  autil.o45
     111        0       12        0      123  math.o45
```

### Full dump

`nm45 -a amain.o45` prints the header, `Text body`/`Data body` hex dumps, the relocations, a `Sizes:` line and the symbols.

## Workflows

```bash
# Who defines / references a symbol
nm45 -A *.o45 | grep _malloc

# All unresolved references
nm45 -u -A *.o45 | awk '{print $NF}' | sort -u

# Exported but never imported by these objects
comm -23 <(nm45 -g -A *.o45 | awk '{print $NF}' | sort -u) \
         <(nm45 -u -A *.o45 | awk '{print $NF}' | sort -u)

# Duplicate strong text exports (a link error)
nm45 -g -A *.o45 | awk '$2=="T" {print $3}' | sort | uniq -d

# Symbols of a library
mkdir tmp && cd tmp && ar45 x ../mylib.lib && nm45 -g *.o45
```

## Supported Formats

Only `.o45` (magic `$01 $00 "o45"`) is accepted. The reader also contains the 16-bit `.o65` code path (selected when the `SIZE32` mode bit is clear) and the `CPU_EXT` handling, but files with the standard `.o65` magic (`"o65"`) are rejected with `invalid magic`. cc65 objects are detected and rejected with a specific message.
