# Glossary

Terms the documentation uses, each with the page that has the details. Addresses are hexadecimal (`$D020`);
a 28-bit address is written `$8000000`.

| Term | Meaning | Details |
|------|---------|---------|
| **45GS02** | The MEGA65's CPU: a 65CE02 (itself a 6502 with a Z register, a movable base page and 16-bit branches) with 32-bit quad instructions on the Q register and 28-bit flat addressing through `[bp],z` | [opcodes.md](../architecture/opcodes.md) |
| **`.o45`** | The relocatable object format: segments, exports, imports, relocations, function attribute records, line and debug information. cc45 `-c` and ca45 `-c` write one, ln45 links them | [lib45.md](../architecture/lib45.md) |
| **`.lib`** | A static library: `.o45` members in an archive made by ar45; ln45 takes only the members a program needs. `c45.lib` (ZP convention) and `c45_stack.lib` (stack convention) are the standard library | [ar45.md](../bin/ar45.md), [stdlib.md](../architecture/stdlib.md) |
| **PRG** | A CBM program file: a 2-byte load address, then the bytes. `ln45 -basic` (and a one-step `cc45 x.c -o x.prg`) starts it with a BASIC line `10 SYS ...`, so `RUN` starts it | [ln45.md](../bin/ln45.md#output-format) |
| **crt0** | The startup code (the library member `crt0`): I/O enabled, the base page moved, the 16-bit stack, BSS filled, `main` called; `__exit` returns to BASIC with the exit status at `$FD/$FE` | [cc45.md](../bin/cc45.md#startup-crt0) |
| **Base page** | The 6502's zero page, which the 45GS02 can put on any page: the B register holds its high byte (`TAB`). A base-page operand (`lda $10`) is one byte shorter and a cycle faster than an absolute one | [calling-conventions.md](../architecture/calling-conventions.md#6-zero-page-base-page-and-interrupts) |
| **Relocated base page** | crt0 moves B to `__zp_page`, a 256-byte page ln45 places at the end of BSS, so a program never writes the ROM's page 0. ROM calls need B = 0: `jsr __bp_rom` / `jsr __bp_prog` around them (see [troubleshooting](troubleshooting.md#rom-calls-from-assembly)) | [calling-conventions.md](../architecture/calling-conventions.md#62-relocated-base-page) |
| **ZP map** | How the program's base page is shared: `$08`-`$0F` scratch, `$10`-`$2F` parameters, `$30`-`$7F` the register pool, `$80`-`$F1` functions' base-page blocks and `__zp` globals, `$F2`-`$FC` temporaries, `$FD/$FE` the frame pointer | [cc45.md](../bin/cc45.md#zero-page-layout) |
| **ZP convention** | The default calling convention (`-fzpcall`, `c45.lib`): arguments packed left to right into the base-page parameter block `$10`-`$2F`. Variadic functions and those with more than 32 bytes of parameters use the stack convention | [calling-conventions.md](../architecture/calling-conventions.md#32-zp-convention) |
| **Stack convention** | `-fno-zpcall` (`c45_stack.lib`): arguments pushed right to left, at least 2 bytes each; the caller removes them | [calling-conventions.md](../architecture/calling-conventions.md#33-stack-convention) |
| **`__fastcall__`** | Makes one function use the ZP convention in a file compiled with the stack convention | [cc45.md](../bin/cc45.md#__fastcall__) |
| **SAC** | Static allocation: a function that is not recursive keeps its parameters and locals in static BSS (`_f__param_x`, `_f__local_N`) instead of a stack frame, with a second entry `_f__sac`. The default (`-fno-staticalloc` turns it off); functions on a call cycle, `__interrupt` handlers and runtime `alloca` get stack frames | [calling-conventions.md](../architecture/calling-conventions.md#5-static-allocation-convention-sac) |
| **SAC overlay** | ln45 lets the storage blocks (`_f__ar`) of SAC functions that are never active at the same time share memory | [ln45.md](../bin/ln45.md#sac-overlay) |
| **Base-page block** | The most used variables of a SAC function that makes calls, kept in `$80`-`$F1` (`-fzp-locals-max=N`; ca45 `.zar`); placed program-wide by ln45 like the SAC overlay | [ln45.md](../bin/ln45.md#base-page-blocks) |
| **Frame pointer** | `$FD/$FE`: set up only by functions that need a stack frame | [calling-conventions.md](../architecture/calling-conventions.md#4-stack-frames) |
| **`__sret`** | The hidden first parameter through which structs, unions, floats and `long long` are returned: a pointer into the caller's storage | [calling-conventions.md](../architecture/calling-conventions.md#2-return-values) |
| **Thunk** | A bridge ln45 generates when a call crosses calling conventions (a ZP caller of a stack-convention function, or the reverse); `--no-thunks` makes a mismatch an error | [ln45.md](../bin/ln45.md#calling-convention-thunks) |
| **`.func_flags`** | ca45's directive for a function's attribute record (convention, leaf, SAC, ISR, clobbers, sizes), which ln45 checks calls against; attached to the symbol of `proc <name>` | [ca45.md](../bin/ca45.md), [lib45.md](../architecture/lib45.md) |
| **16-bit stack** | crt0 runs `CLE` and puts SP at `__stack_top` (`$BFFF`), so the CPU stack is not limited to page 1; `-fno-stack16` keeps the 8-bit stack | [cc45.md](../bin/cc45.md#cpu-stack) |
| **Stack share** | The bytes below the stack top kept for the stack (`__stack_size`, default 4096): the heap ends there. `-fstack-size=N` / `--stack-size=N` | [cc45.md](../bin/cc45.md#heap) |
| **Bank** | A 64 KB part of the 28-bit address space. Bank 0 holds the program (`$C000`-`$CFFF` reads as ROM in C65 mode, so RAM ends at `$BFFF`); banks 1 and 4-5 are chip RAM (bank 1 is BASIC's); the ROM is in banks 2-3 | [cc45.md](../bin/cc45.md#default-memory-map-one-step-build--ln45--basic) |
| **Attic RAM** | The MEGA65's 8 MB of HyperRAM at `$8000000`-`$87FFFFF`, reached only by DMA (slower than chip RAM). Off until a program enables it: `far_attic_enable` / `far_attic_init` (a buddy allocator); copied overlays can be stored there (`--overlay-store`) | [stdlib.md](../architecture/stdlib.md), [ln45.md](../bin/ln45.md#overlays-in-attic-ram) |
| **DMA** | The MEGA65's DMA controller (F018B): copies and fills anywhere in the 28-bit space. `__dma_copy` / `__dma_fill`, `<dma.h>`; crt0 fills BSS with it | [stdlib.md](../architecture/stdlib.md#13-mega65-hardware-megah-and-dma-dmah) |
| **MAP** | The 45GS02 instruction that maps 8 KB blocks of the 16-bit address space to other memory; mapped overlays and `__far` functions run through it | [ln45.md](../bin/ln45.md#mapped-overlays) |
| **Far pointer** | `T __far *p`: 4 bytes, a 28-bit address, read and written with `[bp],z`; reaches banks 1-5 and attic RAM | [cc45.md](../bin/cc45.md#far-pointers) |
| **Near pointer** | `T __near *p`: 1 byte, an offset into the base page (`$00,x`) | [cc45.md](../bin/cc45.md#near-pointers) |
| **Overlay** | Code kept outside bank 0 and brought in when called: a file with `#pragma cc45 overlay(name)` (or `-foverlay=name`) has its code in that overlay; ln45 links all of them to run at one region and calls from outside go through resident stubs to `__ovl_call` | [ln45.md](../bin/ln45.md#code-overlays), [cc45.md](../bin/cc45.md#code-overlays) |
| **Copied / mapped overlay** | A copied overlay is moved into the overlay region by DMA when called (the default); a mapped one (`--overlay-map`) is mapped into a window of `$4000`-`$7FFF` by MAP | [ln45.md](../bin/ln45.md#mapped-overlays) |
| **`.ov1`** | The file ln45 writes with the overlays' code (`<prog>.ov1`, on the disk as `<PROG>.OV1`; `.ov2`... for further banks). crt0's `__ovl_init` loads it into bank 5 at start | [ln45.md](../bin/ln45.md#code-overlays) |
| **`.ovd`** | ln45's description of the overlays and their symbols (`<prog>.ovd`): never loaded, read by nm45 and objdump45 | [nm45.md](../bin/nm45.md), [objdump45.md](../bin/objdump45.md) |
| **`__far` function** | A function kept in far memory: ln45 packs each object's `far` code into automatic mapped overlays `far1`, `far2`... | [cc45.md](../bin/cc45.md#__far-functions) |
| **`__bank(n)`** | A variable kept in bank 4/5 or attic RAM (reached as a far object), or a `__far` function whose overlay is kept in bank n | [cc45.md](../bin/cc45.md#__bankn) |
| **`__zp`** | A global kept in the program's base page (placed by ln45 at the top of `$80`-`$F1`) | [cc45.md](../bin/cc45.md#__zp) |
| **`__interrupt`** | A C function used as an interrupt handler: it saves B and switches to a base page of its own (`__zp_page_isr`) | [calling-conventions.md](../architecture/calling-conventions.md#63-__interrupt) |
| **Unsigned by default** | cc45's plain `char`/`short`/`int`/`long` are unsigned unless declared `signed`; `-fsigned-default` gives standard C (see [troubleshooting](troubleshooting.md#plain-int-is-unsigned)) | [cc45.md](../bin/cc45.md#type-system) |
| **CBM float** | `float`/`double`: the 40-bit (5-byte) format of the BASIC 65 ROM, which computes them (`-ffast-float=1` for RAM routines) | [cc45.md](../bin/cc45.md#type-system) |
| **IR** | cc45's intermediate representation, between the AST and the assembly: what the optimizer works on (`CC45_DUMP_IR=1` shows it) | [ir.md](../architecture/ir.md), [optimizations.md](../architecture/optimizations.md) |
| **Debug file** | `<prog>.dbg` (JSON), written by `cc45 -g` / `ln45 -g`: lines, functions, variables and types for dbg45 | [ln45.md](../bin/ln45.md#debug-file), [dbg45.md](../bin/dbg45.md) |
| **DAP** | The Debug Adapter Protocol: `dbg45 --dap` speaks it, for the VS Code debug type `cc45` | [ide.md](ide.md), [dbg45.md](../bin/dbg45.md) |
| **LSP** | The Language Server Protocol: the language server in `tools/ide/lsp-server` speaks it to editors | [ide.md](ide.md) |
| **`mega65-*` rules** | The linters' rules (al45 for assembly, cl45 for C), configured by `.cc45-lint.yml`, suppressed with `NOLINT` | [al45.md](../bin/al45.md), [cl45.md](../bin/cl45.md), [lint.md](../architecture/lint.md) |
| **KERNAL** | The ROM's operating system routines (`$FFD2` CHROUT, file I/O...) at `$E000` in bank 0's map; `<cbm.h>` wraps them | [stdcbm.md](../architecture/stdcbm.md) |
| **C65 mode / C64 mode** | The MEGA65 starts in C65 mode (BASIC 65, programs at `$2001`); `GO64` switches to C64 mode (programs at `$0801`). cc45's programs are C65-mode programs | [getting-started-c.md](getting-started-c.md) |
| **D81** | The 1581 disk image (800 KB), the MEGA65's native disk format; disk45 makes and changes it and 24 other formats | [disk45.md](../bin/disk45.md) |
| **xemu** | The MEGA65 emulator (`xemu-xmega65`) the runtime tests and dbg45 run programs in; needs a MEGA65 ROM (see [troubleshooting](troubleshooting.md#xemu-and-the-mega65-rom)) | [DOCKER.md](../architecture/DOCKER.md) |
