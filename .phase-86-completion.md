## Key Features

### Call Graph Analysis
- Direct calls: extracted from FunctionCall AST nodes
- Indirect calls: safely excluded (callExpr != nullptr)
- Metrics:
  - `isLeaf`: function makes no calls
  - `incomingCallCount`: total callers
  - `outgoingCallCount`: total callees
  - `isRoot`: never called (except main)

### Devirtualization
- Virtual methods: detected via `isVirtual` flag
- Inheritance: tracked via `parentStruct` field
- Single-implementation detection: enables direct call optimization
- OOP support: struct methods, virtual dispatch, vtable slots

### Co-Optimization
- Inline candidates: functions with 1-3 call sites
- Benefit scoring: accounts for total call overhead
- Safety checks: recursion detection, cycle prevention
- Grouping: identifies related functions for batch optimization
